# 🌌 JARVAS — Trợ Lý AI Thông Minh Thế Hệ Mới Cho Windows

> **Trạng thái:** 🔒 *Private Beta (Đang thử nghiệm nội bộ trước khi phát hành chính thức)*

**JARVAS** là trợ lý AI để bàn thế hệ mới dành riêng cho Windows — kết hợp giao diện Dark-Glass hiện đại, khả năng hiểu ngữ cảnh màn hình/Clipboard tức thì, nhắc việc chủ động bằng giọng nói tiếng Việt và bộ công cụ tiện ích an toàn.

---

## ✨ Điểm Nổi Bật (v1.0)
- **👁️ Hiểu ý nửa lời (Ambient & Clipboard Context):** Tự biết cửa sổ đang mở và đoạn chữ vừa `Ctrl+C` để dịch, giải thích hoặc tóm tắt ngay không cần hỏi lại.
- **💬 Giao diện Dark-Glass Flagship:** Hỗ trợ Markdown, bảng biểu, khối code có nút Copy 1-click, kéo-thả ảnh trực tiếp và thu âm giọng nói tiếng Việt.
- **⏰ Nhắc việc chủ động:** Hiểu mốc thời gian tiếng Việt tự nhiên, tự bật thông báo nổi và đọc nhắc ra loa.
- **🧬 Trí nhớ dài hạn cục bộ:** Ghi nhớ sở thích, thói quen và tự động cập nhật khi có thay đổi.
- **🧰 12+ Công cụ dân dụng an toàn:** Thời tiết & tìm web trực tiếp, tóm tắt YouTube, đọc PDF/Word, dịch nhanh, tạo mã QR, mở ứng dụng/file nhanh, kiểm tra ổ đĩa/RAM, dọn rác tạm.
- **🔐 Bảo mật Windows DPAPI:** API Key được mã hóa cục bộ theo đúng máy tính người dùng, thân thiện 100% với Windows Defender.
