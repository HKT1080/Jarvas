### 1. 👁️ Cảm Nhận Ngữ Cảnh & Hiểu Ý Nửa Lời (Ambient Context)
* **Nhận diện cửa sổ trực tiếp:** JARVAS biết bạn đang đọc báo, viết code, làm báo cáo hay xem tài liệu.
* **Đọc Clipboard thông minh:** Chỉ cần `Ctrl + C` một đoạn tiếng Anh, một dòng lỗi code hoặc một đường link YouTube, rồi hỏi ngắn gọn *"dịch đoạn này"* hoặc *"tóm tắt video vừa copy"*.
* **Phân tích hình ảnh trực quan:** Hỗ trợ kéo-thả trực tiếp ảnh bài tập, hóa đơn, biểu đồ hoặc ảnh chụp màn hình vào khung chat.

### 2. 💬 Giao Diện Flagship Dark-Glass
* Thiết kế tối giản, hiện đại, chạy mượt qua lõi hiển thị sẵn có trên Windows (không cần cài đặt bộ khung nặng nề).

## 🔐 Kiến Trúc Bảo Mật & Quyền Riêng Tư

JARVAS được thiết kế theo nguyên tắc **Local-First (Ưu tiên cục bộ)** và **Zero-Surveillance (Không theo dõi)**:

1. **Mã hóa khóa cứng Windows DPAPI:** API Key của bạn không bao giờ bị lưu dưới dạng văn bản thuần. Ngay khi nhập ở bước thiết lập lần đầu, khóa được mã hóa bằng Windows Data Protection API — chỉ có thể giải mã trên đúng máy tính và đúng tài khoản Windows của bạn.
2. **Không thực thi lệnh hệ thống ẩn:** Phiên bản thương mại v1.0 loại bỏ hoàn toàn các hành vi sinh mã động hoặc chạy script ngầm nhạy cảm, đảm bảo an toàn tuyệt đối và thân thiện 100% với **Windows Defender**.
3. **Minh bạch dữ liệu:** Toàn bộ lịch sử trò chuyện, trí nhớ và ghi chú đều lưu cục bộ trên ổ cứng của bạn; bạn có toàn quyền kiểm tra hoặc xóa sạch bất cứ lúc nào.

## ❓ Câu Hỏi Thường Gặp (FAQ)

<summary><b>1. JARVAS có miễn phí sử dụng không?</b></summary>

Phiên bản v1.0 hoạt động theo cơ chế BYOK (Bring Your Own Key) — bạn có thể dùng Google Gemini API Key miễn phí từ Google AI Studio để trải nghiệm trọn vẹn mà không tốn phí duy trì máy chủ.

<details>
<summary><b>2. API Key và lịch sử trò chuyện của tôi có bị gửi đi đâu không?</b></summary>
<br>
Không. API Key được mã hóa bằng Windows DPAPI trên chính máy tính của bạn. Các câu hỏi chỉ được gửi trực tiếp từ máy bạn tới API của nhà cung cấp AI (Google) để xử lý, không đi qua bất kỳ máy chủ trung gian nào.
</details>

<details>
<summary><b>3. Windows Defender có báo nhầm virus không?</b></summary>
<br>
Không. Toàn bộ mã nguồn bản phát hành v1.0 đều minh bạch, chỉ sử dụng các thư viện chuẩn và không thực thi script hệ thống ẩn.
</details>

<details>
<summary><b>4. Tôi muốn thay đổi API Key hoặc phong cách nói chuyện sau khi cài thì làm thế nào?</b></summary>
<br>
Nhấp chuột phải vào biểu tượng tròn màu xanh của JARVAS ở góc dưới thanh Taskbar (khay hệ thống) và chọn <b>"Đổi API Key / Cài đặt lại"</b>.
